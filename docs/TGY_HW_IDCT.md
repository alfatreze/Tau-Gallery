# TGY hardware IDCT unit (2026-11-12): design and status

RTL: `src/fpga/core/tau_tgy_idct.sv` (modules `tau_tgy_bfly`, `tau_tgy_idct`). Test: `sim/tb_tau_tgy_idct.v` with `sim/gen_tgy_idct_vectors.py`; `make test-rtl-tgy-idct`. Specification it implements: `docs/TGY_RECONSTRUCTION_V0.md` section 3 (libjpeg `jpeg_idct_islow`, bit for bit). **Status: simulated, not synthesised, not fitted, not on a Pocket.**

## Interface
Clock, synchronous reset. `clear` zeroes the coefficient memory (idle only). `we`, `nat[5:0]`, `val[17:0]` write one **dequantised** coefficient at its natural (row-major) index (row = vertical frequency): the dequantisation (coefficient times quantiser) happens upstream, while the entropy decoder delivers the coefficient, so it costs no extra time (a block has 15 to 40 nonzero coefficients and the decoder spends tens of clocks on each). `start` computes the block; `busy`, then per row `px_valid`, `px_row[2:0]`, `px_data[63:0]` (sample k in bits [8k+7:8k]), then a `done` pulse. Writes and `clear` are ignored while busy.

## Structure
- **One 1-D butterfly of 12 multipliers**, five register stages (sums; the 12 products; t2, t3, z3, z4; t10..t13 and the odd terms; the 8 outputs), a vector of 8 values in and 8 out **every clock**, shared by both passes.
- **Pass 1:** the 8 columns of the coefficient memory in 8 clocks; each result is descaled by 11 and written to the 64-entry workspace. **Pass 2:** the 8 rows of the workspace; each result is descaled by 18, range-limited exactly as libjpeg (the low 10 bits of the descaled value select the sample; the wrap beyond +-512 is kept) and delivered as a row of 8 samples.
- **Cost per block (measured in simulation): 30 clocks from `start` to `done`** (8 + 6 + 8 + 6 plus control). A 4:2:0 tile of 384 blocks is 11.5 k clocks, **about 115 microseconds at 100 MHz** against 57 ms in C on the CPU (measured, note section 20). Overlapping the next block's coefficient writes with this block's compute (a second coefficient memory) would hide the 8 + 6 clocks of pass 1 for a block-rate of about 16 clocks; not built, because the entropy decoder, not the IDCT, will set the rate (about 100 clocks and more per block).

## Widths (from the linear weight analysis: the butterfly is linear before the descale, its integer weight matrix has a worst row of absolute sum 61,214)
Input: **18-bit signed dequantised coefficients (|v| < 131,072)**, which covers every valid TGY file (its dequantised coefficients stay below 2^12) and the saturating conformance vectors (+-100,000). Within that range the arithmetic is exact: pass 1 output at most 8.0e9 (34 bits signed), workspace at most 3.9e6 (23 bits, stored in 24), pass 2 output at most 2.4e11 (39 bits, stored in 40; only bits [27:18] reach the sample, so synthesis trims the upper logic). Multipliers: up to 24 x 16 bits (the sums are 19 to 21 bits in pass 1, the workspace values 23 bits in pass 2): Cyclone V's 27 x 27 mode, **12 DSP blocks** (estimate; 11 of 66 are used by the stripped core). Registers: the coefficient memory (64 x 18) and workspace (64 x 24) are plain registers, about 2.7 k flip-flops, plus the pipeline (a few thousand, estimate): no M10K. These counts are estimates until Quartus has seen the module.
A value outside the 18-bit range is not a valid TGY coefficient; a decoder saturates it before the `val` port (the Python and C references use arbitrary precision for such values, which only matters for invalid files).

## Verification
2,870 vectors from the Python reference (arbitrary precision, libjpeg islow): the 20 conformance IDCT cases including saturation, the range-limit corners and the wrap; every impulse (64 positions x 6 values, including +-131,071); 600 dense and sparse small blocks; 300 blocks with a few large coefficients; 600 blocks of input-range extremes; 200 blocks of full-range noise; 768 real photo blocks (dequantised with a real table). **All 2,870 equal the reference bit for bit.** **Nine mutants** (one wrong multiplier constant, swapped outputs, a wrong pass-1 or pass-2 descale, a missing round, a shifted range-limit threshold, a transposed workspace, a missing term of z4, a wrong sign of t12, pass 2 starting a clock early) **are all killed.** Verilator lint reports only width-expansion style warnings (a deliberate wide intermediate).
